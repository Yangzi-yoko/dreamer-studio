**Goal:** 实现 H5 用户端（Vue3 + Vite）：会员注册/登录（无验证码、Redis 防批量注册）、首页（场地/器材/活动入口）、场地租赁流程（列表/详情/选时段/下单/我的订单）、器材租赁流程（商品/租期/下单/我的租单）、活动展示与报名、会员中心（积分/储值/次卡/优惠券/邀请码）。

**Architecture:** 后端新增 `modules/member-auth/`：会员注册（手机号+昵称，无验证码）签发会员 JWT，Redis 限流（同 IP 每小时 N 次 + 设备指纹关联数）；`Member` 增加 `passwordHash` 不需要（无密码），用手机号+随机盐 token 会话。H5 为独立 Vue3 项目 `web/`，复用现有公开接口（`rental/studios`、`rental/bookings`、`rental/items`、`rental/item-rentals`、`member/activities`），会员接口带会员 JWT。

**Tech Stack:** NestJS 10、TypeORM、MySQL 8、redis 4.x、Vue 3.4、Vite 5、Pinia、Vue Router 4、Axios、Element Plus（移动端轻量使用）。

## Global Constraints

- 会员注册：`POST /api/member-auth/register`（phone + nickname，无验证码），重复手机号抛 `BusinessException('手机号已注册', 40030)`；登录 `POST /api/member-auth/login`（phone + nickname 匹配或手机号直接登录）
- 防批量注册：Redis key `reg:ip:{ip}` 计数（每小时 5 次上限）、`reg:finger:{fingerprint}` 关联账号数（≤3），超限抛 `BusinessException('注册太频繁，请稍后再试', 40060)`
- 会员 JWT：payload `{ sub: memberId, type: 'member' }`，`MemberAuthGuard` 校验，`@CurrentMember()` 装饰器
- 租赁下单接口需带 `memberId`（现有公开接口改造：可选 memberId，传了则关联会员）
- H5 路由：`/`（首页）、`/studios`、`/studio/:id`、`/booking/:studioId`、`/items`、`/item/:id`、`/item-rental/:itemId`、`/activities`、`/activity/:id`、`/member`（会员中心）、`/login`、`/register`、`/orders`、`/rentals`
- 中文文案；H5 使用移动端友好的简单布局（Element Plus 基础组件）
- 新实体/守卫注册到对应模块；管理后台菜单不变
- 当前环境已恢复提权：可提交/推送/部署

- [ ] **Step 2: 实现服务**

Create `backend/src/modules/member-auth/member-auth.service.ts`:

```typescript
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { JwtService } from '@nestjs/jwt';
import { Repository } from 'typeorm';
import { RedisService } from '../../common/redis/redis.service';
import { BusinessException } from '../../common/exceptions/business.exception';
import { Member } from '../member/entities/member.entity';

const IP_LIMIT = 5;
const FINGERPRINT_LIMIT = 3;

@Injectable()
export class MemberAuthService {
  constructor(
    @InjectRepository(Member) private readonly memberRepo: Repository<Member>,
    private readonly jwtService: JwtService,
    private readonly redis: RedisService,
  ) {}

  private sign(member: Member): string {
    return this.jwtService.sign({ sub: member.id, type: 'member' });
  }

  async register(phone: string, nickname: string, ip: string, fingerprint: string): Promise<{ accessToken: string; member: any }> {
    const ipCount = Number((await this.redis.get(`reg:ip:${ip}`)) || 0);
    if (ipCount >= IP_LIMIT) throw new BusinessException('注册太频繁，请稍后再试', 40060);
    const fpCount = Number((await this.redis.get(`reg:finger:${fingerprint}`)) || 0);
    if (fpCount >= FINGERPRINT_LIMIT) throw new BusinessException('注册太频繁，请稍后再试', 40060);

    const exists = await this.memberRepo.findOneBy({ phone });
    if (exists) throw new BusinessException('手机号已注册', 40030);
    const member = await this.memberRepo.save(this.memberRepo.create({ phone, nickname }));

    await this.redis.set(`reg:ip:${ip}`, ipCount + 1, 3600);
    await this.redis.set(`reg:finger:${fingerprint}`, fpCount + 1, 86400);
    return { accessToken: this.sign(member), member: { id: member.id, phone, nickname } };
  }

  async login(phone: string): Promise<{ accessToken: string; member: any }> {
    const member = await this.memberRepo.findOneBy({ phone });
    if (!member) throw new BusinessException('会员不存在', 40400);
    return { accessToken: this.sign(member), member: { id: member.id, phone, nickname: member.nickname } };
  }
}
```
