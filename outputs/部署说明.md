## 常用操作

```bash
# 查看后端状态
pm2 status
pm2 logs dreamer-api

# 重启后端（代码改动后）
cd /www/wwwroot/backend && npm run build && pm2 restart dreamer-api

# 管理后台重新构建（改动 admin/src 后）
cd /www/wwwroot/admin && npm run build -- --base=/admin/

# H5 重新构建（改动 web/src 后）
cd /www/wwwroot/web && npm run build

# 数据库
mysql -u dreamer_user -pDreamerStudio2026Db dreamer_studio
```

## 注意事项

- 后端配置在 `/www/wwwroot/backend/.env`，目前开启了自动建表（DATABASE_SYNC=true），方便开发迭代；进入稳定期后建议改为 false。
- 棚景等接口有 1 小时 Redis 缓存，直接改数据库后如需立即生效，执行 `redis-cli FLUSHDB`。
- Nginx 配置在 `/etc/nginx/sites-available/dreamer.conf`。
- 微信小程序 AppID（wx37aa826b283cb708）已写在项目配置中，小程序源码目录暂未在压缩包内发现完整内容，接入时需补充；后端 `.env` 中的 WECHAT_APPID / WECHAT_SECRET 也需要填写。
- 服务器仅开放了 SSH 和 HTTP 端口，API 通过 Nginx 转发，未对外暴露 3000 端口。
